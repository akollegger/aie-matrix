# Implementation Plan: Eval Contracts Between Ghosts

**Branch**: `024-eval-contracts` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `specs/024-eval-contracts/spec.md`

## Summary

Implement the `EvalContract` primitive from [RFC-0022](../../proposals/rfc/0022-eval-contract-protocol.md): a 1:1 service agreement between a client ghost (who stakes resources), a contractor ghost or group (who fulfills a request), and an evaluator ghost (who scores the result). Settlement is an atomic ledger transaction that pays the contractor proportionally and returns the remainder to the client. Implementation follows the established `LedgerService` / `GroupService` pattern: Effect `Context.Tag` interface, in-memory unit-testable layer, Neo4j-backed live layer, and MCP tools registered in `mcp-server.ts`.

## Technical Context

**Language/Version**: TypeScript 5.7 / Node.js 24 (ESM, `"type": "module"`)  
**Primary Dependencies**: `effect` v3+, `neo4j-driver` v5, `@modelcontextprotocol/sdk` 1.29+, `ulid`, `zod` 3 — all already in `server/world-api`  
**Storage**: Neo4j (`(:EvalContract)` nodes); in-memory `Map` for unit tests  
**Testing**: `vitest` (unit: in-memory layer, no live services); integration tests skip when `NEO4J_URI` absent  
**Target Platform**: Node.js server (`server/world-api`)  
**Project Type**: Domain service + MCP tool layer within existing monorepo package  
**Performance Goals**: Settlement must complete in a single atomic Neo4j write transaction; no notable throughput target beyond existing world-api baseline  
**Constraints**: Zero residual in escrow after settlement (enforced by floor arithmetic); submission immutability enforced at service layer  
**Scale/Scope**: Same session scale as the existing ledger and group services

### Phase 2 — Error Types

**File**: `server/world-api/src/eval-contract-errors.ts`

Define `Data.TaggedError` classes following `ledger-errors.ts` pattern:

| Error class | Tag | When |
|---|---|---|
| `EvalContractNotFound` | `EvalContractError.NotFound` | Contract ID unknown |
| `EvalContractWrongState` | `EvalContractError.WrongState` | Transition not allowed from current state |
| `EvalContractNotAuthorized` | `EvalContractError.NotAuthorized` | Caller is not the required role |
| `EvalContractInvalidEvaluator` | `EvalContractError.InvalidEvaluator` | Evaluator is the contractor or a beneficiary |
| `EvalContractDeadlineExpired` | `EvalContractError.DeadlineExpired` | Submission attempted after deadline |
| `EvalContractPersistenceError` | `EvalContractError.PersistenceError` | Neo4j write/read failure |

Export a `EvalContractError` union type of all of the above.

### Phase 3 — Service Interface

**File**: `server/world-api/src/EvalContractService.ts`

```typescript
export interface EvalContractServiceOps {
  openContract(params: { ... }): Effect.Effect<EvalContract, ...>
  acceptContract(params: { contractId, callerId }): Effect.Effect<EvalContract, ...>
  declineContract(params: { contractId, callerId }): Effect.Effect<EvalContract, ...>
  submitContract(params: { contractId, callerId, submission }): Effect.Effect<EvalContract, ...>
  evaluateContract(params: { contractId, callerId, verdict }): Effect.Effect<EvalContract, ...>
  getContract(contractId): Effect.Effect<EvalContract, EvalContractNotFound>
  listContracts(params: { callerId, state? }): Effect.Effect<EvalContract[], never>
}

export class EvalContractService extends Context.Tag("world-api/EvalContractService")<
  EvalContractService,
  EvalContractServiceOps
>() {}
```

`openContract` depends on `LedgerService` and `GroupService` (injected via Effect context). `evaluateContract` triggers settlement internally.

---

### Phase 4 — In-Memory Implementation + Unit Tests

**Files**: `server/world-api/src/EvalContractServiceInMemory.ts`, `server/world-api/src/EvalContractService.test.ts`

In-memory Layer backed by a `Map<EvalContractId, EvalContract>`. Uses `LedgerServiceInMemory` and `GroupServiceInMemory` as peer dependencies in tests.

**Unit test coverage required** (all against in-memory layer):

| Method | Happy path | Error path(s) |
|---|---|---|
| `openContract` | Contract created, stake debited | Insufficient funds, evaluator = contractor |
| `acceptContract` | State → Accepted; beneficiaries frozen for group | NotFound, WrongState, NotAuthorized |
| `declineContract` | State → Declined; escrow returned | NotFound, WrongState, NotAuthorized |
| `submitContract` | State → Submitted; immutable | NotFound, WrongState, DeadlineExpired |
| `evaluateContract` | State → Settled; correct settlement math (ghost) | NotFound, WrongState, InvalidEvaluator |
| `evaluateContract` | Group contractor: correct per-share math + remainder | — |
| `getContract` | Returns record | NotFound |
| `listContracts` | Filters by caller role and state | — |

Settlement invariant test: `contractorPayment + clientRefund === stakeAmount` for any integer stake and any verdict in [0,1].

---

### Phase 5 — Neo4j Live Implementation

**File**: `server/world-api/src/EvalContractServiceLive.ts`

Neo4j `Layer` that:
- Creates `(:EvalContract)` nodes on `openContract`
- Updates `state`, `beneficiaries`, `submission`, `verdict` properties atomically via Cypher `MATCH … SET`
- `listContracts` uses a Cypher `WHERE` clause filtering by `clientId`, `contractorId`, or `evaluatorId`
- All ledger calls delegate to `LedgerService` (the live layer in production)

Integration tests skip when `NEO4J_URI` is not set. When run, they cover the same method × error matrix as unit tests.
